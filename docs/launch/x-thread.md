1. ARPE is a local board for directing AI agents. You write the Result (what must be true) and Purpose (why it matters). The agent owns the plan, does the work and records proof.

2. A finished card is not the same as a passing Check. ARPE keeps the plan and the test of the Result separate. If the Check fails, the work needs attention even if the cards say done.

3. When the agent needs your judgement, it puts a question in the board’s decision inbox. Goals, answers and a resume note live in project files so a fresh session can pick up the work.

4. Try the included countdown example. The replay runs a real browser test, shows the evidence on the board and asks whether to keep the page local. No AI account is needed for the replay.

5. The kit runs locally on Windows, macOS and Linux. Use `arpe new` to create a project and `arpe open` to start a separately installed, signed-in Claude Code session. It is not an autonomous agent runner.

6. The repository has the install walkthrough, recorded video and an illustrated book explaining the method. Start here: https://github.com/gberlian/arpe
