# ARPE, simply

A reader's path through the illustrated book. Start with what you want to achieve, then learn how a project keeps its plan, evidence and decisions in writing. You do not need to know how to program to read it.

The book describes the wider ARPE method and the system in which it was developed. Some illustrations and chapters describe an earlier kit or private automation; they are not a list of features shipped here. For the current public command, editable owner board, automatic declared Checks, local notes and sharing, use the [Guide](GUIDE.md). The public kit does not automatically run agents, deliver handoffs or manage private desktop workspaces.
