# Handoff: one finished deliverable

## Goal
Describe the finished, testable thing in one sentence.

## Inputs
List each attached file or archive and why it matters. Provide a sanitized copy only.

## Constraints
Relevant language, runtime, permissions, boundaries, and exclusions.

## Deliverables
Name every output path and format. Return complete files, not a summary of edits.

## Work
1. Inspect attached inputs and verify assumptions.
2. Implement the deliverable.
3. Run checks and include their real output.

## Acceptance
Commands and observable behaviors the parent ray will independently test.

## Return
Send finished files or one archive, check output, and known limitations. The parent ray reviews and applies the result.
